WsgiDAV Explorer

Help

This is the help page for the WsgiDAV Explorer. It provides a user interface to browse and manage files on a WebDAV server.

Features

  • Browse directories and files on a WebDAV server.
  • Upload files to the server.
  • Create new folders.
  • View file details and metadata.
  • Search for files and folders.
  • Logout from the current user session.

Usage

Click a row to select a file or folder. Its actions are available from the context menu: right-click the row, click the ⋮ button at the end of the row, or press the Menu key or Shift+F10. Right-click empty space for actions on the root folder. The button next to ⋮ is a shortcut to download a file or to upload files into a folder.

Keyboard shortcuts

  • F2: rename
  • Del (macOS: ⌘+⌫): delete
  • Ctrl+X / C / V (macOS: ⌘): cut, copy, paste. Paste puts the item into the selected folder, or next to the selected file.
  • Esc: clear the clipboard

Files and folders can also be moved by drag and drop, and files can be uploaded by dropping them onto the tree.
